## 🔍 How to Use This Library

1. **Browse by Category**: Click on any category link above to see all patches of that type across all synths
2. **Find by Synth**: Each category file is organized by synthesizer
3. **Patch Numbers**: Most patches include their original patch numbers for easy recall
4. **Descriptions**: Detailed descriptions help identify the right sound for your project

---

## 📝 Notes

- All patch numbers are preserved from original factory banks
- Custom patches are marked with creator initials (e.g., "jd -", "*C")
- Poly Evolver patches use bank notation (A001-D128)
- Some patches appear in multiple categories when they serve dual purposes
- Patch descriptions include sonic characteristics and typical use cases
